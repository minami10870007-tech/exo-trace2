EXO-TRACE 利用者登録

Netlify の環境変数 EXO_USERS に貼る文字列を作ります

計算はこのブラウザの中だけで行います。入力したメールアドレスやパスワードはどこにも送信されません。

1. ログインする人を入力

パスワードは12文字以上。「自動作成」を押すと推測されにくいパスワードを作ります。

2. Netlify に貼る

下の値をコピーして、Netlify の Site configuration → Environment variables の EXO_USERS に貼り付け、再デプロイします。

EXO_USERS の値例
利用者に伝える内容
メールアドレスパスワード
taro@example.com（例）Kx7p-Qm2v-Ra9d

パスワードは本人にだけ伝えてください。このページを閉じると表示は消えます。

SESSION_SECRET の値最初の1回だけ

ログイン状態の署名に使うランダムな文字列です。初めて設定するときに1回だけ作り、Netlify の SESSION_SECRET に貼ります（作り直すと全員がログアウトされます）。

  1. Netlify で EXO_USERS に貼り付けて保存
  2. Deploys → Trigger deploy で再デプロイ
  3. サイトを開き、上のメールアドレスとパスワードでログイン
